# Contributing to Monke Bot
Thanks for taking a look! It means a lot! :D

Monke Bot is open to contributions of all forms. These include (but aren't exclusive to):
- Issue submissions (Bug reports, feature requests, etc...)
- New features
- Hotfixes

## Submitting an issue
If you notice a bug or you have an idea for a new feature, the best way to bring it forward is by submitting an issue (Please ensure that an existing issue isn't open already!).

### If you've spotted a bug:
1. Label the issue as a bug and briefly elaborate in the title.
2. Dive into further detail with a full description. Please include relevant media and/or console outputs if possible. If you can consistently replicate the bug, document the steps you took.

### If you want to request a feature:
1. Label the issue as an enhancement and briefly elaborate in the title.
2. Dive into further detail with a full description. Feel free to include relevant media.

## Creating a new feature
If you'd like to bring something new to Monke, I'm happy to apply it as long as it's safe to integrate and use. Here's what will happen:
1. Fork the repository and commit your changes to a feature branch off `Development`.
2. When you're done, create a pull request into my `Development` branch. Add me (SweetBoy13735) as a reviewer of the changes.
3. Once all tests have passed and I'm happy, I'll approve the merge!

## Writing a hotfix
If you'd like to take on a bug, here's what you'll need to do:
1. Fork the repository and commit your fixes to a hotfix branch off `Main`.
2. When you're done, create a pull request into my `Main` branch. Add me (SweetBoy13735) as a reviewer of the changes.
3. Once all tests have passed and I'm happy, I'll approve the merge!
