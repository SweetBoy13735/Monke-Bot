# Monke Bot
[![Contributor Covenant](https://img.shields.io/badge/Contributor_Covenant-v3.0_adopted-900.svg)](https://GitHub.com/SweetBoy13735/Monke-Bot/blob/Main/CODE_OF_CONDUCT.md)

*"**Ook, Ook!**"*
This is an interactive Discord bot that is centred around... Well... Monkes!

Monke Bot is built with my [Discord.js bot Boilerplate](https://GitHub.com/SweetBoy13735/Discord.js-bot-Boilerplate).

## Support
If you encounter any odd behaviour, please feel free to [create an issue](https://GitHub.com/SweetBoy13735/Monke-Bot/issues) or [E-Mail me](mailto:Ramone@SweetBoy13735.Me.UK).

## Roadmap
Development of the bot will be subject to required updates at any given time.

I'll be using the [Git Flow](https://nvie.com/files/Git-branching-model.pdf) branching method to keep track of all changes.
